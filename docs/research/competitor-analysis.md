# 桌面整理工具竞品分析

> **调研时间**：2026-11-12
> **范围**：Windows 桌面整理/收纳类工具，含栅栏分区、Dock 美化、布局守护、AI 归类四类。
> **信息口径**：以厂商官网、Microsoft Store 页面与公开报道为准；部分产品的细分能力可能随版本变化，落地前建议复核。
> **配套**：功能取舍见 [`docs/roadmap/backlog.md`](../roadmap/backlog.md)，扩展方式见 [`docs/design/extension-model.md`](../design/extension-model.md)。

---

## 1. 结论摘要

1. **栅栏分区是红海**：Fences、Nimi Places、腾讯桌面整理、360 桌面助手、小智桌面都在做，差异主要在"自动分类、文件夹门户、搜索、速度"。
2. **"拖入"是标配，"拖出"同样是标配**——只做单向拖放会被用户直接感知为缺陷。
3. **自动分类规则**是各家最核心的留存点，但都必须可预览/可撤销，否则会打乱用户布局。
4. **文件夹门户（Folder Portal / Places）**是与"只引用、不移动"哲学最契合的差异化能力，Sylva 目前完全空缺。
5. **可靠性功能（撤销、布局快照、快速隐藏）**成本低、感知强，优先级应高于视觉增强。

## 4. 各产品要点

### Fences 6（Stardock）
- **Automation rules**：按文件类型/名称等规则自动把新图标归入对应栅栏。
- **Folder Portals**：把任意文件夹（含云盘目录）镜像成栅栏，内容实时同步。
- **Peek**：悬停/快捷方式快速查看栅栏内的项目。
- **Roll up**：栅栏卷起为标题条，节省桌面空间。
- **Quick hide**：一键隐藏所有栅栏与图标。
- **Tabs / Pages**：多页栅栏，应对栅栏数量膨胀。

### Nimi Places
- 容器化（Places）与高度可定制：每容器独立尺寸、主题、强调色、视图模式（网格/单列/多列详情）。
- 完整的 DPI 缩放、无障碍、多语言与自动更新——**工程完成度**是它的优势。

### 腾讯桌面整理
- 格子/区域划分 + **一键自动分类**（按类型归入格子）。
- **常用文件映射桌面**（等价于文件夹门户的轻量版）。
- **全盘文件精准搜索**；双击隐藏桌面图标。

### 360 桌面助手
- 自动整理、分类归纳；**本地秒搜**；待办提醒；壁纸/动态桌面；截图、护眼等"全家桶"能力。
- 说明：这些附加能力与"轻量原生"定位冲突，只建议借鉴搜索/待办，不建议跟进壁纸与系统工具。

### 小智桌面
- 一键整理、文件分区、快速搜索启动、待办 + 日历 + 倒数日、壁纸/组件，并已引入 AI 组件。

### MyDockFinder
- 仿 macOS Dock、WinUI 模糊/云母材质、运行程序窗口预览——属于**美化**赛道，与栅栏定位不同。

### DesktopOK
- **保存/恢复桌面图标位置**、多套布局方案；功能极简但解决了"布局被系统打乱"这一强痛点。

### WisFile（AI 派）
- 本地 AI 解析 PDF/DOCX 内容，做自动归类与重命名——代表"按内容而不是按扩展名"的整理方向。

## 5. 对标结论

**Sylva 的既有优势**

- 原生 Rust + D2D/DComp，无 WebView，资源占用与启动速度有结构性优势；
- 桌面接管方式低风险（不注入 DLL、不替换 shell），与 Wallpaper Engine 共存；
- 已有侧边栏 Dock、磁吸、夹屏、多屏/DPI、模糊背景、待办插件等基础；
- 本地化、无账号、隐私友好。

**主要差距**

| 差距 | 影响 |
|---|---|
| 只能拖入、不能拖出 | 拖放闭环不完整，用户第一周就会踩到 |
| 无撤销 / 无回收队列 | 误删误移不可恢复，信任成本高 |
| 无布局快照 | 单个 `desk.json` 损坏即布局全丢 |
| 无自动分类 / 文件夹门户 | 与"整理"这一核心诉求的竞品差距最大 |
| 无搜索 | 图标多起来后查找效率低 |
| 无快速隐藏 | 演示/录屏/专注场景缺少"一键清爽" |

## 6. 功能建议（与 backlog 对应）

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | 拖出（`SHDoDragDrop`）、撤销 + 回收队列、布局快照、Quick hide、开机自启 | 可靠性闭环，竞品标配 |
| P1 | 自动分类规则、文件夹门户、卷起、栅栏内搜索、Peek、多页、每栅栏外观 | 差异化与效率 |
| P2 | 快捷键自定义 | 用户可预期的小能力 |

详见 [`docs/roadmap/backlog.md`](../roadmap/backlog.md)。

---

## 7. 不建议跟进

- 壁纸/动态桌面、截图、护眼、清理加速等"全家桶"能力；
- 云同步/账号体系；
- 直接移动/重命名/复制磁盘文件（违背"只引用、不移动"）；
- 强制自动整理（必须默认关、可预览、可撤销）；
- Dock 化（与栅栏定位冲突，属于另一款产品）。
