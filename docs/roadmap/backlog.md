## 2. P0 · 可靠性闭环

### SYL-P0-01 拖出（`SHDoDragDrop`）

- **状态**：待开发
- **目标**：从栅栏把文件/文件夹拖到桌面或资源管理器，行为与系统拖放一致。
- **验收**：
  - [ ] 拖出单个/多个文件到桌面成功，文件位置不变（只发生系统语义上的移动/复制）。
  - [ ] 拖出到资源管理器窗口、其他应用（如微信、浏览器上传区）成功。
  - [ ] 拖出过程中原栅栏项显示正确的"拖拽中"状态，完成后状态清除。
  - [ ] 拖出失败（目标拒绝）时文件不丢失、不重复，UI 恢复。
  - [ ] 不伪造拖放源，`IDataObject` 使用系统 `CF_HDROP`。
- **依赖/风险**：与现有 `WM_DROPFILES` 拖入路径互不干扰；需处理 COM `DoDragDrop` 的模态消息循环（期间不能重入事件处理）。
- **关联**：需求文档 §4.2。

### SYL-P0-02 撤销与回收队列

- **状态**：待开发
- **目标**：删除收纳项可撤销，撤销记录持久化，重启仍可恢复。
- **验收**：
  - [ ] 删除收纳项后进入回收队列，UI 可撤销。
  - [ ] 撤销记录写入持久化，重启应用后仍可撤销。
  - [ ] 删除**不删除磁盘文件**；撤销后引用与图标恢复。
  - [ ] 回收队列有容量上限与淘汰策略。
  - [ ] 批量删除产生单条可撤销事务（而非 N 条）。
- **依赖/风险**：依赖 core 领域命令与存储抽象；与 P0-03 快照共用持久化路径。
- **关联**：需求文档 §2.5。

### SYL-P0-03 布局快照与自动备份

- **状态**：待开发
- **目标**：布局损坏或误操作可一键恢复到最近可用状态。
- **验收**：
  - [ ] 每次结构性变更（新增/删除栅栏、批量移动）前自动生成快照，保留最近 N 份。
  - [ ] 启动时若主配置解析失败，自动回退到最近快照并记录日志。
  - [ ] 提供"恢复上一份快照"的 UI 入口。
  - [ ] 快照文件写入遵循 write temp → rename（AGENTS §2.2）。
- **依赖/风险**：存储层改造（JSON → redb）期间需兼容迁移。
- **关联**：需求文档 §3.4；竞品对标 DesktopOK / Fences Snapshot。

### SYL-P0-04 Quick hide 快速隐藏

- **状态**：待开发
- **目标**：一键隐藏所有栅栏与桌面图标，再按一次恢复。
- **验收**：
  - [ ] 全局热键/托盘菜单可切换隐藏。
  - [ ] 隐藏时栅栏不拦截鼠标（区域置空），桌面可正常操作。
  - [ ] 退出/崩溃恢复路径不受影响（恢复逻辑仍只负责真实图标）。
- **依赖/风险**：与"隐藏真实图标"的 IconGuard 语义区分——Quick hide 只隐藏本应用视觉。
- **关联**：竞品 Fences Quick hide / 腾讯双击隐藏。

### SYL-P0-05 开机自启

- **状态**：待开发
- **目标**：设置项 `settings.autostart` 真正生效。
- **验收**：
  - [ ] 开启后写入当前用户启动项（注册表 `Run` 或启动文件夹），卸载时清除。
  - [ ] 关闭后移除启动项。
  - [ ] 自启失败（无权限、路径变化）记录日志并在设置页提示。
  - [ ] 安装器卸载流程同时清理启动项。
- **依赖/风险**：与安装器卸载逻辑联动；避免需要管理员权限。

## 3. P1 · 效率与差异化

### SYL-P1-01 自动分类规则

- **状态**：待开发
- **目标**：按扩展名/名称/时间/来源把桌面图标或拖入项归入指定栅栏。
- **验收**：
  - [ ] 规则可预览（`--dry-run` 等价的 UI 预览），默认关闭。
  - [ ] 规则命中后产生**显式状态迁移**，不得让同一文件在两处显示。
  - [ ] 规则可撤销；批量应用前自动快照。
  - [ ] 规则冲突有确定顺序（显式优先级），并在 UI 中可见。
  - [ ] 规则持久化并可在 CLI/JSON 接口中读写。
- **依赖/风险**：依赖 P0-02/P0-03；注意与"手动拖拽"定位的冲突——默认关闭。
- **关联**：需求文档 §2.3；竞品 Fences rules、腾讯智能分类。

### SYL-P1-02 文件夹门户（Folder Portal）

- **状态**：待开发
- **目标**：把真实文件夹映射为一个只读/可操作的栅栏，内容随磁盘变化同步。
- **验收**：
  - [ ] 可把任意文件夹添加为门户栅栏，刷新后显示其内容（含子项策略可配置）。
  - [ ] 文件在外部新增/删除/重命名后，栅栏在合理延迟内同步。
  - [ ] 门户栅栏的拖入仍遵循"引用不移动"；拖出遵循系统语义。
  - [ ] 文件夹不可访问/被删除时降级显示，不崩溃。
  - [ ] 云盘/网络路径不阻塞主线程（列目录放到后台）。
- **依赖/风险**：文件监听（`ReadDirectoryChangesW`）成本与节流；与现有"显式成员列表"模型并存需明确优先级。
- **关联**：Fences Folder Portals / Nimi Places。

### SYL-P1-03 卷起 Roll-up

- **状态**：待开发
- **目标**：栅栏折叠为标题条，节省桌面空间。
- **验收**：
  - [ ] 点击标题栏按钮或双击标题栏可折叠/展开。
  - [ ] 折叠状态持久化；重启后保持。
  - [ ] 折叠时窗口区域与命中测试同步收缩，区域外点击穿透。
  - [ ] 折叠/展开有过渡动画且不阻塞消息循环。
- **依赖/风险**：模型已有 `FenceState::Folded`，主要补 UI 与区域计算。
- **关联**：Fences Roll up。

### SYL-P1-04 栅栏内搜索 / 过滤

- **状态**：待开发
- **目标**：在单个栅栏内按名称快速过滤，栅栏多/图标多时可用。
- **验收**：
  - [ ] 栅栏激活时输入即过滤（内存内，不走磁盘索引），`Esc` 清除。
  - [ ] 过滤不影响成员顺序与持久化数据。
  - [ ] 空结果有明确提示。
  - [ ] 输入法组合期间不误触发。
- **依赖/风险**：与现有内联编辑/输入焦点模型复用，避免抢焦点。
- **关联**：360/小智"秒搜"的轻量版；全局启动器留待 L4 扩展。

### SYL-P1-05 Peek 悬停预览

- **状态**：待开发
- **目标**：悬停折叠栅栏或图标堆叠时快速查看内容。
- **验收**：
  - [ ] 悬停标题栏 N 毫秒后浮层显示内容预览，移开消失。
  - [ ] 浮层不拦截鼠标，不遮挡其他栅栏交互。
  - [ ] 预览内容与栅栏当前成员一致。
- **依赖/风险**：纯 render 层；注意与 tooltip 的层级和节流。

### SYL-P1-06 多页 / Tabs

- **状态**：待开发
- **目标**：栅栏数量膨胀后，用分页组织栅栏集合。
- **验收**：
  - [ ] 可创建/重命名/删除页，页内栅栏独立布局。
  - [ ] 切换页有明确动画与快捷键。
  - [ ] 每页布局独立持久化，崩溃恢复后回到上次页。
- **依赖/风险**：数据模型需引入 Page 层级，属于结构性变更，需先改需求文档。
- **关联**：Fences 6 Tabs。

### SYL-P1-07 每栅栏独立外观

- **状态**：待开发
- **目标**：在全局主题之上，允许每个栅栏单独设置颜色/透明度/字体。
- **验收**：
  - [ ] 控制中心可为选中栅栏设置色调、透明度、字体大小。
  - [ ] 设置持久化，重启保持。
  - [ ] 与全局主题变更的优先级明确（栅栏覆盖全局）。
- **依赖/风险**：`FenceAppearance.tint` 已存在，补齐透明度/字体与 UI。

## 4. P2 · 小能力

### SYL-P2-01 快捷键自定义

- **状态**：待开发
- **目标**：用户可修改控制中心、Quick hide、退出等全局热键。
- **验收**：
  - [ ] 设置页可录制/清除/恢复默认热键。
  - [ ] 冲突检测（被系统或其他应用占用时提示）。
  - [ ] 热键配置持久化，重启生效。
  - [ ] 注册失败不影响应用启动，仅记录日志。
- **依赖/风险**：`settings.hotkeys` 结构已存在，主要是 UI 与 `RegisterHotKey` 生命周期。
- **关联**：需求文档 §5（AI 接口不涉及）。

## 5. 不进本轮待开发（扩展包候选）

| 能力 | 建议归属 | 说明 |
|---|---|---|
| 日历 / 倒数日 | 进程内面板插件（L2） | 复用现有待办插件骨架 |
| 主题 / 皮肤包 | 声明式数据包（L3） | 只读数据，无代码执行 |
| 多语言 | 声明式数据包（L3） | 语言资源包 |
| 自动更新 | 进程外工具（L4） | 独立更新器，主进程不联网 |
| AI 自然语言整理 | 进程外工具（L4） | 复用需求文档的 JSON CLI |
| 拖放动画 / 无障碍 | 核心（L0） | 属于核心体验，不做成扩展 |

详见 [扩展模型](../design/extension-model.md)。
